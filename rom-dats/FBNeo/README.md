# FBNeo DAT

The arcade DAT is pinned to the FBNeo revision used by **NextUI v6.15.0**, distributed as **NextUI-20261013-0**.

| Reference | Value |
|---|---|
| DAT | `FinalBurn Neo (ClrMame Pro XML, Arcade only).dat` |
| FBNeo commit | `6a5cc250c2db8d874a06ee86e302a2a78918b4c1` |
| DAT Git blob SHA-1 | `00ef248b98bebba167111d4d16de76b15b65956d` |

This DAT includes Neo Geo arcade sets. A separate Neo Geo DAT is unnecessary for this catalogue.

When upgrading NextUI, check its pinned FBNeo revision before updating this DAT. The DAT's `1.0.0.03` version label alone does not identify the exact revision.

- [NextUI release](https://github.com/LoveRetro/NextUI/releases/tag/v6.15.0)
- [NextUI build configuration with the FBNeo pin](https://github.com/LoveRetro/NextUI/blob/v6.15.0/workspace/tg5040/cores/makefile)
- [Pinned DAT download](https://raw.githubusercontent.com/libretro/FBNeo/6a5cc250c2db8d874a06ee86e302a2a78918b4c1/dats/FinalBurn%20Neo%20%28ClrMame%20Pro%20XML%2C%20Arcade%20only%29.dat)

The Git blob SHA-1 identifies the DAT file itself, not any individual game ROM. It hashes the file bytes with Git's blob header.
