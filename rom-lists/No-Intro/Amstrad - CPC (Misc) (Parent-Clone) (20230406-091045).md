## Intent

A one-game starter from the installed CPC Misc DAT. This catalogue contains only Gilligan's Gold, so retaining it says nothing about the breadth or quality of the wider CPC library. A substantial CPC collection needs a more representative catalogue.

## The selection

**Gilligan's Gold** is a qualified inclusion: a compact, Bagman-style arcade game about carrying gold back to a wheelbarrow while navigating ladders, lifts and pursuing enemies. Carrying the gold complicates the return trip, giving the simple premise a useful risk-and-reward hook. Keep it as an approachable diversion, rather than presenting it as a defining CPC masterpiece.

The original instructions support joystick play as well as keyboard controls. Selecting the control scheme or starting play may still need a keyboard action; a suitable handheld mapping should preserve the action button.

## Release and scope decisions

- Select the exact **Gilligan's Gold (World) (Steam).dsk** entry. The Steam tag identifies this catalogue release; it is not a reason to rename the disk or substitute another dump.
- Keep the `.dsk` image intact. There is only one selected disk and no multipart set to assemble.
- The separate CPC Flux DAT contains preservation captures in `.hxcstream` and `.raw` form. Those files are not additional ready-to-launch disks for this manifest. Converting and cataloguing them would be a separate preservation workflow.
- Games absent from this small DAT have not been rejected through curation. Do not interpret the one-game list as a completed survey of CPC gaming.

Caprice32 documents `.dsk` loading and joystick/keyboard mappings. The game list records a selection, not a claim that the installed NextUI setup has been tested. A broader CPC catalogue can complement this DAT-based manifest without changing the verified filename here.

## Sources informing the choice

- [Original Gilligan's Gold instructions, preserved by CPC-Power](https://www.cpc-power.com/index.php?num=979&onglet=notices&page=detail): objectives, joystick support and controls.
- [Amstrad Computer User, May 1985](https://device.report/m/6045569333c3aefe69ed8575a07e8ac2e23b2ceaf5674f66c0365dc07309ceb8): contemporary assessment of the mine navigation and timed gold collection.
- [Caprice32 documentation](https://docs.libretro.com/library/caprice32/): supported disk formats and keyboard handling.
